# QuitHide

[English](README.en.md)

QuitHide 是一个原生 macOS 菜单栏工具，可以在 App 离开前台一段时间后，按独立规则自动隐藏或正常退出它。

![QuitHide 菜单栏界面](assets/quithide-screenshot.png)

## 功能

- 未单独设置的 App 可在离开前台后按默认时间自动隐藏
- 为每个 App 分别设置“不处理”“隐藏”或“退出”
- 为每条自动规则单独设置等待时间
- 显示剩余时间和即将执行的动作
- App 重新激活后开始新的计时周期
- 一键提前隐藏或退出符合规则的 App
- 随时暂停自动处理
- 可选登录时启动
- 默认每天自动检查一次更新，也可在设置中手动检查
- 不处理、自动隐藏和自动退出规则在 App 未运行时仍会显示
- “不处理”App 与其他规则使用相同的横向列表；未运行时灰色显示

## 系统要求

- macOS 13 Ventura 或更高版本
- Apple Silicon 或 Intel Mac（Universal 2）

## 下载与安装

1. 从 [GitHub Releases](https://github.com/jiangsir-tech/QuitHide/releases) 下载最新的 `.dmg`。
2. 打开 DMG，把 `QuitHide.app` 拖到“应用程序”文件夹。
3. 启动 QuitHide，然后点击菜单栏图标设置规则。

正式发布的安装包使用 Apple Developer ID 签名并经过 Apple 公证。请只从本仓库的 Releases 页面下载安装包。

## 使用说明

首次安装时，设置中“附加规则”的两个开关均保持关闭。需要时可以分别开启；开启后默认等待时间为 5 分钟，也可以自行修改。

主界面默认显示“运行中”，依次列出不处理、未设置、自动隐藏和自动退出，因此点开菜单就能看到当前所有 App。“全部规则”保留不处理、自动隐藏和自动退出三组，其中只显示明确设置过的规则；每组标题同时显示总数和运行中数量。组内正在运行的 App 优先，其余按英文名称或中文拼音自然排序，未运行的 App 会灰色显示。

菜单窗口会根据当前正在运行的 App 和分组数量自动调整高度；达到上限后列表改为滚动。“全部规则”和搜索结果沿用同一高度，切换或输入时不会让窗口来回跳动。

搜索时会合并显示匹配结果，不再按规则类型拆分；清除搜索后恢复原有分组。

在 App 右侧选择“不处理”“隐藏”或“退出”可以覆盖默认规则。“不处理”表示 QuitHide 不隐藏也不退出该 App；单独设置的隐藏和退出规则会保存自己的等待时间。显式规则即使在 App 未运行时也会保留并显示为灰色，规则控件仍可编辑。

底部的“立即隐藏”和“立即退出”会提前执行当前正在运行 App 的对应规则，不会修改规则或等待时间。即使自动处理已暂停，手动执行仍然可用。

“退出”使用 macOS 的正常退出请求，不会强制结束进程；未保存内容是否提示由目标 App 自己决定。

正常退出请求发出 30 秒后，如果 App 仍在运行，状态会显示“退出未完成”。可以再次右击选择正常退出，也可以选择“强制退出…”并经过二次确认。强制退出只允许用户手动触发，自动规则绝不会使用；强制退出可能导致未保存内容丢失。

“自动检查更新”默认开启，启动后延迟检查，且最多每 24 小时检查一次。发现兼容当前 macOS 的新稳定版本后，QuitHide 会在下次打开菜单时提醒；可以前往下载、稍后 24 小时再提醒，或跳过当前版本。自动检查可以在设置中关闭，手动“检查更新”始终可用。QuitHide 只负责提醒并打开本项目的 GitHub Releases 页面，不会自行下载、安装或重启 App。

## 隐私

QuitHide 在本机运行，不包含分析服务或第三方依赖，也不会上传正在运行的 App 列表和用户规则。启用自动检查更新时，QuitHide 最多每 24 小时执行一次检查：先访问本项目的 GitHub 更新清单，清单不可用时可能继续查询 GitHub Releases，并读取候选稳定版本 tag 中的兼容性清单；无法确认系统兼容性时不会提供该版本。手动检查使用同一流程。请求只用于比较版本，不包含 App 列表或用户规则。

## 从源码构建

需要 Apple Swift 工具链。

先运行核心逻辑回归测试：

```sh
./scripts/test.sh
```

然后构建 Universal 2 App：

```sh
./scripts/build-app.sh
```

维护者可使用钥匙串中保存的公证凭据生成签名并公证的发布包：

```sh
./scripts/release-notarized.sh
```

生成供 GitHub Releases 分发的 DMG 和 SHA-256 校验文件：

```sh
./scripts/build-dmg.sh
```

构建结果位于 `dist/`。
