Core features

Per-app rules

Choose Automatic Hide, Automatic Quit, or Ignore; optional window protection avoids acting on groups or windows still in use.

Privacy and safety

Your rules stay on your Mac.

  • Does not upload your running-app list or rules
  • No analytics service or advertising SDK
  • Visible-window protection never reads screen contents; group protection uses Accessibility only after you enable it
  • Automatic Quit uses the standard macOS quit request and never force-quits automatically
  • Stable releases are Developer ID signed and notarized by Apple

FAQ

Questions before downloading.

Does QuitHide force-quit other apps?

Not automatically. Automatic Quit sends the standard macOS quit request, so the target app can show its normal save prompt. Force Quit is available only as a manual, confirmed action in an app's context menu.

Are apps without a rule automated?

Not on a fresh installation. Both Additional Rules switches are off until you explicitly enable them.

Does QuitHide connect to the internet?

All rule execution is local. Network access is used only to check for stable updates; QuitHide does not upload your app list or rules.

Why is there no Mac App Store version?

The independently distributed build keeps the complete app-management behavior and uses Apple's Developer ID signing and notarization process.
