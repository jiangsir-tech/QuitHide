常见问题

下载前可能关心的问题。

QuitHide 会强制结束其他 App 吗？

自动退出不会。它发送 macOS 标准退出请求，由目标 App 决定是否显示保存提示。只有你在右键菜单中手动选择“强制退出”并再次确认时，才会强制结束。

未设置规则的 App 会被自动处理吗？

新安装时不会。两项附加规则默认关闭，只有你明确开启后才会作用于未设置规则的 App。

QuitHide 会联网吗？

规则执行完全在本机完成。联网仅用于检查稳定版更新，不会上传 App 列表或规则。

为什么没有 Mac App Store 版本？

独立分发版本保留了完整的 App 管理能力，并使用 Apple 官方的 Developer ID 签名和公证流程。
